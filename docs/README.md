# OpenVQ documentation

## Current status

The default `main` branch is the stable baseline.

The latest research milestone is Phase 6.1 on `validation/phase6`.

Phase 6.1 selected a compact hybrid sequence model under a frozen leave-one-corpus-out rule. The candidate passed ONNX parity and failed the independent engineering promotion gate, so it was not promoted.
